CHETAN PRICE FINDER — FIRST VERSION

This folder contains a mobile-first static price search website built from:
RETAILER INVOICE AUGUST- 2026

Features:
- Public-link friendly static website
- Mobile-first design
- Partial/fuzzy search across category, sweep and model
- Type “BLDC” to see all matching products
- Click a result to see Model, Category, Sweep and Invoice Price
- Only Invoice price is shown
- No separate product-code field was invented because the source PDF does not provide one

IMPORTANT:
A public URL requires hosting. The files are ready to upload to a static host such as GitHub Pages, Netlify, Cloudflare Pages, etc.

MONTHLY UPDATE:
The first version is deliberately structured so the product data can later be moved to a database/backend. That is the recommended next step if you want a secure admin page where you upload the next month's price list and everyone sees the update automatically.
